## Overview
Demonstration of frontend performance optimization techniques:
1. **Native Image Lazy Loading**: Using `loading="lazy"` on image elements to defer downloading assets outside the initial viewport.
2. **Client-Side Storage Caching**: Storing dynamic timestamps and data in local browser storage to eliminate redundant network re-fetching.
